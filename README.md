# Power BI Sales Dashboard

## Project Overview
This project is an interactive Sales Dashboard created using Power BI to analyze sales performance, profits, regions, and customer segments.

## Features
- Sales by Category
- Sales by Segment
- Sales by Region
- Sales Trends by Year
- Profit Analysis
- Interactive Filters

## Tools Used
- Power BI
- DAX
- Data Visualization
- Excel

## Dashboard Preview
![Dashboard](dashboard.png)

## Key Insights
- Total Sales: $2M
- Total Profit: $286K
- Highest sales observed in West region
- Consumer segment generated highest revenue
